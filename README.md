# Laboratorio de Programación Web - Práctica 3 (Aplicación Interactiva)

Alumna: Andrea Fernanda Rodriguez Niño 2160663 ITS

Repositorio que contiene el desarrollo de la aplicación web interactiva del lado del cliente utilizando JavaScript.

Descripción del Proyecto:
Aplicación web tipo gestor de tareas académicas diseñada para administrar información del lado del cliente sin dependencia de un servidor backend.

Herramientas Utilizadas
* HTML5 : Estructura de la interfaz y elementos semánticos.
* CSS3 : Diseño adaptativo.
* JavaScript ES6+ : Lógica de negocio, objetos, arreglos, funciones flecha y template literals.
* Web APIs : localStorage para persistencia de datos.
* Control de versiones : GitHub

Funciones (CRUD)
1. Crear y Registrar : Permite agregar nuevas tareas especificando nombre y nivel de prioridad.
2. Visualizar : Muestra los registros en una tabla dinámica en tiempo real.
3. ¿Editar y Actualizar : ¿ Modifica registros existentes de manera intuitiva.
4. Eliminar : Borra elementos individuales del sistema.
5. Persistencia Local : Los datos se guardan automáticamente en el navegador usando `localStorage`, evitando que se pierdan al recargar la página.
6. Búsqueda y Contadores : Filtra tareas en tiempo real y muestra un cálculo automático de pendientes y totales.

 Instrucciones de Ejecución
1. Clona este repositorio o descarga el archivo `index.html`.
2. Haz doble clic en el archivo `index.html` o ábrelo directamente en cualquier navegador.
3. Puedes interactuar con el gestor de tareas directamente.
